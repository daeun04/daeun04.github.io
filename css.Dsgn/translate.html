Transform - translate()

CSS transform 속성은 기준점(transform-origin)을 설정하여 HTML 요소의 시각적 형태와 위치를 다채롭게 변형하는 기능으로, 이동(translate), 회전(rotate), 크기 조절(scale), 기울이기(skew) 등의 전용 메서드와 이들을 결합한 행렬 연산(matrix)을 통해 2D 및 3D 그래픽 효과를 자유롭게 구현할 수 있게 해줍니다.
translate(300px, 50px)
빨강박스
오른쪽 300px, 아래쪽 50px 이동
translateX(150px)
초록박스
X축 150px 이동
translateY(-20px)
파랑박스
Y축 -20px 이동
