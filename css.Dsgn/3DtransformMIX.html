transform:
  translate3D(20px, -15px, 60px)
  scale3d(1.15, 1.15, 1.5)
  rotate3d(1, 1, 0, 45deg);
  • translate3D: X축(오른쪽 20px), Y축(위로 15px), Z축(화면 밖 60px)으로 3차원 이동합니다.
  • scale3d: 전체 크기를 1.15배 확대하고 깊이(Z축) 비율을 1.5배 확장합니다.
  • rotate3d: X축과 Y축 대각선 축을 기준으로 입체감 있게 45도 회전합니다.
