01 자식 선택자  ›  Child Selector Combinator

직계 자식만 선택한다

> 기호를 사용하며, 부모 요소의 바로 아래 직계 자식만 선택합니다. 손자·증손자 등 더 깊은 자손 요소에는 스타일이 적용되지 않습니다. 중첩 구조에서 정밀하게 범위를 제어할 때 유용합니다.

부모 > 자식 { }

Live Demo

.parent > .child {
  color: lime;
}
/* .grandchild 에는 미적용 */

02 속성 선택자  ›  Attribute Selector Attribute

HTML 속성 값으로 선택한다

대괄호 [ ] 안에 속성명 또는 속성값을 지정하여 요소를 선택합니다. ^=은 "시작 값", $=는 "끝 값", *=는 "포함 값"을 의미합니다. 링크 유형 구분, 파일 형식 스타일링 등에 강력합니다.

a[href^="https"] { }

Live Demo

a[href^="https"] { color: lime; }
a[href^="http:"] { color: red; }
a[href^="mailto"] { color: cyan; }
  • https:// → 보안 링크 (초록)
  • http:// → 비보안 링크 (빨강)
  • mailto: → 이메일 링크 (청록)
03 :nth-child()  ›  순서 기반 가상 클래스 Pseudo-Class

N번째 자식을 수식으로 선택한다

:nth-child(n)은 부모 안에서 몇 번째 자식인지를 기준으로 선택합니다. odd(홀수), even(짝수), 또는 2n+1 같은 수식도 사용 가능합니다. 표·목록의 줄무늬(zebra) 패턴 구현에 자주 쓰입니다.

tr:nth-child(odd) { }

Live Demo — 홀짝 줄무늬 테이블

tr:nth-child(odd)  { background: lime/10%; }
tr:nth-child(even) { background: red/5%; }

04 ::before / ::after  ›  가상 요소 Pseudo-Element

HTML을 건드리지 않고 콘텐츠를 삽입한다

::before와 ::after는 요소의 앞뒤에 CSS만으로 가상의 콘텐츠를 삽입합니다. content 속성이 필수이며, 장식용 아이콘·기호·오버레이 등 HTML을 오염시키지 않는 시각 요소 추가에 이상적입니다.

li::before { content: "▶"; }

Live Demo

li::before {
  content: "▶";
  color: orange;
}
.item::before { content: "「"; }
.item::after  { content: "」"; }
  • CSS만으로 앞에 ▶ 아이콘 삽입됨
  • HTML 마크업 변경 없이 스타일 제어
  • 장식, 오버레이, 툴팁 등에 활용

05 일반 형제 선택자  ›  General Sibling ~ Combinator

같은 부모의 뒤따르는 형제를 모두 선택한다

~는 같은 부모 아래에서 기준 요소 뒤에 오는 모든 형제를 선택합니다. 바로 인접한 형제만 선택하는 +(인접 형제)와 달리, 뒤에 있는 형제 전체에 적용됩니다. 체크박스 핵(checkbox hack) 등 JS 없는 UI 토글에 활용됩니다.

input:checked ~ .sibling { }

Live Demo — 체크박스로 형제 스타일 변경

input:checked ~ label {
  color: lime;
}
input:checked ~ .items .item {
  border-left: 2px solid lime;
}
형제 요소 A
형제 요소 B
형제 요소 C

※ 체크박스를 클릭하면 ~ 선택자로 형제 스타일이 바뀝니다

06 :focus-within  ›  포커스 전파 가상 클래스 Pseudo-Class

자식에 포커스가 오면 부모를 선택한다

:focus-within은 해당 요소 또는 그 자손 요소 중 하나라도 포커스를 받으면 부모 요소에 스타일을 적용합니다. 폼 그룹 전체를 강조하거나, 카드 내부 입력 시 카드 전체를 하이라이트하는 등 인터랙티브 UI에 매우 유용합니다.

.form:focus-within { border-color: cyan; }

Live Demo — 입력 시 폼 전체 하이라이트

.form:focus-within {
  border-color: cyan;
  box-shadow: 0 0 0 3px cyan/12%;
}

↑ 입력창 클릭 시 :focus-within 이 부모 .form 에 적용됩니다
