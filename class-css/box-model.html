CSS Border, Margin, Padding and Box Shadow Examples

1. Border Styles

solid border

solid는 가장 기본적인 실선 경계선입니다.

dotted border

dotted는 점선 형태의 경계선입니다.

dashed border

dashed는 긴 점선 형태의 경계선입니다.

double border

double은 두 줄로 표시되는 경계선입니다.

groove border

groove는 파인 듯한 입체 경계선입니다.

ridge border

ridge는 튀어나온 듯한 입체 경계선입니다.

inset border

inset은 안쪽으로 들어간 듯한 경계선입니다.

outset border

outset은 바깥쪽으로 튀어나온 듯한 경계선입니다.

2. Margin

This box has margin.

margin은 요소의 바깥쪽 여백입니다. 다른 요소와의 거리를 만들 때 사용합니다.

This box uses margin-top.

margin-top은 요소의 위쪽 바깥 여백을 지정합니다. 이외에도 margin-right, margin-bottom, margin-left가 있습니다.

3. Padding

This box has padding.

padding은 요소의 안쪽 여백입니다. 내용과 경계선 사이의 간격을 만들 때 사용합니다.

This box uses padding-left.

padding-left는 요소의 왼쪽 안쪽 여백을 지정합니다. 이외에도 padding-top, padding-right, padding-bottom이 있습니다.
