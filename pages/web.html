웹 프로그래밍

1. HTML 소개

HTML(hyper text markup language, 하이퍼텍스트 마크업 언어)은 웹페이지의 구조를 만드는 언어입니다.

2. CSS 소개

CSS(cascading style sheets, 종속형 스타일 시트)는 웹페이지의 색상, 배치, 글자 크기 등 디자인을 담당합니다.

3. 자주 쓰는 HTML 태그

  • <h1> ~ <h6> : 제목
  • <p> : 문단
  • <a> : 링크
  • <img> : 이미지
  • <table> : 표

4. 예시 코드

<h1>나의 홈페이지</h1>
<p>웹 프로그래밍 수업 정리입니다.</p>
<a href="index.html">메인으로 이동</a>
메인으로 돌아가기
