String 객체란?

String 메서드는 문자열을 검색 · 추출 · 변경 · 변환하는 기능입니다. 문자열을 한 글자씩 직접 고치지 않고, JavaScript가 제공하는 메서드로 편리하게 다룰 수 있습니다.

  • 문자열의 글자마다 0부터 시작하는 번호(인덱스)가 붙습니다. 첫 글자가 0번입니다.
  • 메서드는 원래 문자열을 바꾸지 않고, 새 결과를 돌려줍니다.

1. 예제 9-4 · String 속성과 prototype

생성자 함수로 객체를 만들고, prototype으로 공통 속성을 추가한 뒤 length, constructor 값을 출력하는 예제입니다.

// 9-4 String 속성
function Human(name, job, birth) {   // 생성자 함수
    this.name = name;
    this.job = job;
    this.birth = birth;
}
Human.prototype.age = 23;    // 모든 Human이 함께 쓰는 속성

var kim = new Human("Kim", "student", 2003);
kim.name.length;    // "Kim"의 글자 수
kim.age;            // prototype에서 가져온 값
kim.constructor;    // kim을 만든 함수

2. 예제 9-5 · String 메서드 1

글자 꺼내기(charAt, charCodeAt), 이어 붙이기(concat), 위치 찾기(indexOf, lastIndexOf), 바꾸기(replace)입니다.

// 9-5 String 메소드1
var str = "hello, welcome to AI Software!!";
var str2 = "???";
str.charAt(0);           // 0번 글자
str.charCodeAt(0);       // 0번 글자의 문자 코드
str.concat(str2);        // 두 문자열 잇기
str.indexOf("AI");       // "AI"가 처음 나오는 위치
str.lastIndexOf("to");   // "to"가 마지막으로 나오는 위치
str.replace("hello", "Good Bye");  // 바꾸기

3. 예제 9-6 · String 메서드 2

검색(match, search), 잘라내기(slice), 나누기(split), 대문자 변환(toUpperCase), 문자열 변환(toString)입니다.

// 9-6 String 메소드2
var str = "Hello, welcome, AI, Software";
var str2 = 5678;
str.match("AI");          // 일치하는 부분 찾기
str.search("Software");   // 시작 위치
str.slice(7, 12);         // 7번부터 11번까지
str.split(" ");           // 공백으로 나누기
str.toUpperCase();        // 모두 대문자로
str2.toString();          // 숫자를 문자열로

4. String 메서드 정리

예제에 나온 메서드를 기능별로 묶었습니다. 예시는 str = "hello, welcome to AI Software!!" 기준입니다.

위치 찾기

메서드설명예시결과
indexOf(값)처음 나오는 위치. 없으면 -1str.indexOf("AI")18
lastIndexOf(값)마지막으로 나오는 위치. 없으면 -1str.lastIndexOf("to")15
search(값)indexOf와 비슷. 정규식도 쓸 수 있음str.search("AI")18
match(값)일치하는 부분을 배열로 돌려줌. 없으면 nullstr.match("AI")["AI"]

꺼내기

메서드설명예시결과
length글자 수 (속성이라 괄호 없음)str.length31

바꾸기 · 변환

메서드설명예시결과
replace(a, b)처음 나오는 a를 b로 바꿈str.replace("hello", "Hi")"Hi, welcome to AI Software!!"
concat(s)뒤에 문자열을 이어 붙임 (+와 같음)"AI".concat("!!")"AI!!"
split(구분자)구분자로 잘라 배열로 만듦"a-b-c".split("-")["a", "b", "c"]
toUpperCase()모두 대문자로"ai".toUpperCase()"AI"
toLowerCase()모두 소문자로"AI".toLowerCase()"ai"
trim()앞뒤 공백 제거" AI ".trim()"AI"
toString()문자열로 변환(5678).toString()"5678"
주의: replace는 처음 하나만 바꿉니다. 모두 바꾸려면 replaceAll을 씁니다. 예: "AI는 AI다".replaceAll("AI", "인공지능") → "인공지능는 인공지능다"
