Math 객체란?

Math는 수학 계산에 필요한 상수와 함수를 모아 둔 JavaScript 내장 객체입니다. new로 만들지 않고 Math.PI, Math.round(1.5)처럼 바로 사용합니다.

  • 상수(속성): Math.PI처럼 정해진 값. 이름이 모두 대문자입니다.
  • 메서드: Math.sqrt(4)처럼 값을 넣으면 계산 결과를 돌려주는 함수입니다.

1. 예제 코드

Math 객체의 상수 8개를 화면에 출력하는 예제입니다. 출력할 자리를 <b id="...">로 만들어 두고, 스크립트에서 innerHTML로 값을 채웁니다.

<!DOCTYPE html>
<html>
<head>
    <title>예제 9-9 Math 속성</title>
</head>
<body>

<h3>Math 객체 속성</h3>

<!-- 값이 들어갈 자리. id로 구분합니다 -->
<p>Euler's 상수(E) : <b id="ca"></b></p>
<p>자연로그2 LN2 : <b id="cca"></b></p>
<p>자연로그10 LN10 : <b id="cnct"></b></p>
<p>2진로그E(LOG2E) : <b id="ido"></b></p>
<p>10진로그E(LOG10E): <b id="fxd"></b></p>
<p>PI : <b id="prc"></b></p>
<p>SQRT1_2 : <b id="str"></b></p>
<p>SQRT2 : <b id="vlf"></b></p>

<script>
    // id로 요소를 찾아 Math 상수 값을 넣습니다
    document.getElementById("ca").innerHTML = Math.E;
    document.getElementById("cca").innerHTML = Math.LN2;
    document.getElementById("cnct").innerHTML = Math.LN10;
    document.getElementById("ido").innerHTML = Math.LOG2E;
    document.getElementById("fxd").innerHTML = Math.LOG10E;
    document.getElementById("prc").innerHTML = Math.PI;
    document.getElementById("str").innerHTML = Math.SQRT1_2;
    document.getElementById("vlf").innerHTML = Math.SQRT2;
</script>

</body>
</html>

코드 흐름

  1. <p> 안의 빈 <b> 태그가 값을 출력할 자리입니다. ca, cca, prc 같은 고유 id를 붙여 구분합니다.
  2. document.getElementById("id")로 해당 요소를 찾습니다.
  3. .innerHTML = Math.E처럼 Math 상수 값을 요소 안에 넣으면 화면에 표시됩니다.

3. Math 메서드

괄호 안에 숫자를 넣으면 계산 결과를 돌려줍니다. 비슷한 기능끼리 묶었습니다.

정수 만들기 · 절댓값

메서드설명예시결과
Math.ceil(x)올림. x보다 크거나 같은 정수 중 가장 작은 수Math.ceil(1.234)2
Math.floor(x)내림. x보다 작거나 같은 정수 중 가장 큰 수Math.floor(1.234)1
Math.round(x)반올림. 가장 가까운 정수Math.round(1.234)1
Math.trunc(x)소수점 아래를 버리고 정수 부분만 남김Math.trunc(1.234)1
Math.abs(x)절댓값Math.abs(-3)3

최댓값 · 최솟값 · 난수

메서드설명예시결과

Math.min(...)넣은 값 중 가장 작은 수Math.min(1, 3, 0.3, 12)0.3
Math.random()0 이상 1 미만의 무작위 수. 실행할 때마다 바뀜Math.random()0.…

1~6 주사위 만들기: Math.floor(Math.random() * 6) + 1. random()에 6을 곱하면 0 이상 6 미만이 되고, floor로 내려서 0~5, 1을 더해 1~6이 됩니다.

4. 올림 · 내림 · 반올림 · 버림 비교

양수 1에서는 네 메서드 결과가 모두 같아서 차이가 안 보입니다. 다른 값을 넣어 보면 차이가 드러납니다. 특히 음수에서 floor와 trunc가 달라집니다.
