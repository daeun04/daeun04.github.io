JavaScript 출력 방식 4가지 완벽 가이드

자바스크립트에서 데이터를 화면이나 콘솔에 출력하는 대표적인 방법 4가지를 실습과 함께 배워봅시다.

1

innerHTML (요소 내부 변경)

가장 많이 사용하는 방식!
HTML 문서 내의 특정 태그(요소)를 찾아 그 안의 내용(텍스트 또는 HTML)을 바꿉니다.

💡 동작 방식: `document.getElementById('아이디')`로 태그를 선택한 뒤, `.innerHTML`을 이용해 내용을 삽입합니다.
document.getElementById("demo1").innerHTML =
  "<span style='color:blue'>출력 완료!</span>";
여기에 결과가 출력됩니다.
2

document.write() (문서에 직접 쓰기)

HTML 문서 전체에 직접 글자를 출력합니다.
⚠️주의: 페이지가 다 로딩된 후에 실행하면 기존 화면 내용이 전부 삭제되고 새 내용만 남습니다. (테스트용으로만 주로 사용)

💡 동작 방식: HTML 로딩 과정 중에 실시간으로 텍스트를 출력 스트림에 밀어 넣습니다.
document.write("화면에 직접 텍스트를 작성합니다.");
버튼을 누르면 이 가이드 페이지 전체가 덮어씌워집니다. (새로고침으로 복구 가능)
3

window.alert() (경고창 팝업)

브라우저 상단에 메시지 알림(팝업창)을 띄웁니다.
사용자가 '확인' 버튼을 누르기 전까지는 다음 코드의 실행이 멈춥니다.

💡 동작 방식: 브라우저 자체 대화상자를 호출하여 사용자에게 중요한 정보를 알릴 때 사용합니다.
window.alert("반갑습니다! 경고창 출력입니다.");
// 'window.' 생략 가능: alert("내용");
버튼을 눌러 팝업창을 띄워보세요.
4

console.log() (개발자 도구 콘솔)

웹 페이지 화면에는 보이지 않고, 브라우저 **개발자 도구(F12)**의 [Console] 탭에만 출력됩니다.
개발자가 코드의 오류(버그)를 찾거나 값을 확인할 때 필수적으로 씁니다.

💡 동작 방식: 키보드 F12를 누른 뒤 'Console' 탭을 켜면 출력된 메시지를 확인할 수 있습니다.
console.log("개발자 도구 콘솔에 출력되는 메시지입니다.");
> F12를 누르거나, 버튼을 클릭해 가상 콘솔 출력을 확인하세요.
