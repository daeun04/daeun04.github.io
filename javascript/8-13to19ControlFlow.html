예제 8-13 if-else 조건문

핵심: if (조건) A; else B; — 조건이 참이면 A, 거짓이면 B. new Date().getHours()로 현재 시(0~23)를 얻습니다. 윤년은 %(나머지)와 &&, ||로 판단합니다.

원본 문제수정
함수 이름 time()/year()가 요소 id "time"/"year"와 같고, 함수 안 변수 year도 함수 이름과 같음 — 동작은 하지만 헷갈리고 충돌 위험showTime(), checkLeapYear(), 결과 id yearResult로 구분
<!DOCTYPE html> 앞에 빈 줄, <script> 두 개로 나뉨DOCTYPE을 맨 첫 줄로, script 하나로 합침
시간 표시가 숫자만 나옴 (예: 14)"14시"로 표시
charset 없음<meta charset="UTF-8"> 추가
수정한 전체 코드 보기

<html lang="ko">

function showTime() {
    var clock = new Date().getHours();                 // 현재 시(0~23)
    document.getElementById("time").innerHTML = clock + "시"; // 문서에 시간 표시
    if (clock < 18) alert("좋은 하루!");                // 오후 6시 이전이면
    else alert("잘 쉬어요!");                           // 오후 6시부터
}
function checkLeapYear() {
    var year = parseInt(document.getElementById("yearInput").value); // 입력창에서 값 읽기
    var result;
    if (isNaN(year)) {
        result = "연도를 숫자로 입력해 주세요.";
    }
    // 윤년: 4의 배수이면서 100의 배수가 아니거나, 400의 배수
    else if ((year % 4 === 0 && year % 100 !== 0) || (year % 400 === 0)) {
        result = year + "년은 윤년입니다.";
    } else {
        result = year + "년은 평년입니다.";
    }
    document.getElementById("yearResult").innerHTML = result; // 문서에 결과 표시
}
</script>
</head>
<body>

예제 8-15 switch-case 조건문

핵심: 값이 일치하는 case로 바로 이동해 실행하고, break를 만나면 빠져나옵니다. 어느 것도 맞지 않으면 default. (break를 빼면 다음 case까지 이어서 실행됨)

원본 문제수정
<b id="grade">클릭하세요 </p> — <b> 닫는 태그 누락</b> 추가
학점 입력 함수 이름이 time() — 내용과 맞지 않음 (8-14 복사 흔적)inputGrade()
prompt()의 두 번째 인자 "A-F 사이의 문자로"는 안내문이 아니라 입력창에 미리 채워지는 값이라, 그대로 확인을 누르면 "잘못입력". 또 "A-F 사이"라고 하면 E도 되는 것처럼 보임안내는 첫 번째 인자에 (A, B, C, D, F)로 명시하고, 기본값은 빈 문자열 ""
소문자 a나 공백 포함 입력 시 "잘못입력"trim().toUpperCase()로 정리 후 비교
prompt에서 취소(null) 시 "잘못입력" 표시null이면 아무것도 안 함
} } 한 줄에 닫기 등 정렬 불량, charset 없음정리
수정한 전체 코드 보기
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="UTF-8">
<title>예제8-15 switch case문</title>
<script>
function inputGrade() {
    var grade = prompt("성적을 입력하시오 (A, B, C, D, F):", ""); // 두 번째 인자 = 미리 채워질 값
    var out = document.getElementById("grade");
    if (grade === null) return;              // 취소를 누른 경우
    grade = grade.trim().toUpperCase();      // 소문자 a도 A로 처리
    switch (grade) {
        case "A": out.innerHTML = "A학점입니다."; break;
        case "B": out.innerHTML = "B학점입니다."; break;
        case "C": out.innerHTML = "C학점입니다."; break;
        case "D": out.innerHTML = "D학점입니다."; break;
        case "F": out.innerHTML = "F학점입니다."; break;
        default:  out.innerHTML = "잘못 입력했습니다...";
    }
}
</script>
</head>
<body>
<h3>switch case 조건문</h3>

핵심: for (초기식; 조건식; 증감식) — 반복 횟수가 정해져 있을 때 사용. 초기식 → 조건 검사 → 실행 → 증감 → 조건 검사… 순서로 돌고, 조건이 false면 끝납니다.

<Script> 대문자, }가 출력문 줄 끝에 붙어 있음정리
charset 없음추가
수정한 전체 코드 보기
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="UTF-8">
<title>예제8-16 for 반복문</title>
<!--
  for (초기식; 조건식; 증감식) { 실행할 코드; }
  초기식 실행 → 조건식 검사 → 코드 실행 → 증감식 실행 → 조건식 검사 … (false이면 종료)

예제 8-17 이중 for문 (구구단 2~18단)

핵심: for문 안에 for문을 넣으면 바깥 1회당 안쪽이 전부 돕니다. 바깥 = 행(단), 안쪽 = 열(곱하는 수). 요청대로 18단까지 확장했습니다.

원본 문제수정
단은 1~9, 곱하는 수는 2~9 → 1단이 들어가고 ×1이 빠진 잘못된 구구단단 2~18, 곱하는 수 1~9
표에 머리글이 없어 몇을 곱한 값인지 알 수 없음머리글 행(×1 ~ ×9)과 단 표시를 <th>로 추가
결과 숫자만 출력2×3=6 형식으로 출력
<table> 태그 안에 <script>를 넣고 document.write로 태그를 조각조각 출력 — 구조상 불안정문자열로 표 전체를 만든 뒤 한 번에 출력
<!DOCTYPE html>, charset 없음, 주석이 실제 동작과 다름추가 및 주석 정정
수정한 전체 코드 보기
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="UTF-8">
<title>예제8-17 이중 for문 구구단 (2~18단)</title>
<style>
    table { border-collapse: collapse; }
    th, td { border: 1px solid #888; padding: 4px 8px; text-align: right; }
    th { background: #eee; }
</style>
</head>
<body>
<h3>이중 for문을 이용한 구구단 (2단 ~ 18단)</h3>
<script>
    var html = "<table>";
    var x, y;                                  // 반복에 쓸 변수는 한 번만 선언

    // 머리글 행: ×1 ~ ×9
    html += "<tr><th>단</th>";
    for (y = 1; y <= 9; y++) html += "<th>×" + y + "</th>";
    html += "</tr>";

    // 바깥 for문: 2~18단 (행)
    for (x = 2; x <= 18; x++) {
        html += "<tr><th>" + x + "단</th>";
        // 안쪽 for문: 1~9 곱하기 (열)
        for (y = 1; y <= 9; y++) {
            html += "<td>" + x + "×" + y + "=" + (x * y) + "</td>";
        }
        html += "</tr>";
    }
    html += "</table>";
    document.write(html); // 완성된 표를 한 번에 출력
</script>
</body>
</html>

예제 8-18 while 반복문

핵심: while (조건) — 조건을 먼저 검사하고 참인 동안 반복. 반복 횟수를 모를 때 주로 사용합니다. 안에서 x++처럼 조건을 바꾸지 않으면 무한 반복됩니다.

원본 문제수정
코드 자체는 정상 (0~99 출력)—
탭/공백 들여쓰기 혼용, <Script> 대문자, charset 없음정리
수정한 전체 코드 보기
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="UTF-8">
<title>예제8-18 while 반복문</title>
</head>
<body>
<h3>while 반복문</h3>
<script>
    var x = 0;
    while (x < 100) {               // 조건이 참인 동안 반복 (먼저 검사)
        document.write("while : " + x + "<br>");
        x++;                         // 빠뜨리면 무한 반복!
    }
</script>
</body>
</html>

예제 8-19 do while 반복문

핵심: do { … } while (조건); — 먼저 한 번 실행한 뒤 조건을 검사합니다. 조건이 처음부터 거짓이어도 최소 1번은 실행되는 것이 while과의 차이입니다.

원본 문제수정
}while ( x < y) 뒤 세미콜론 없음 — JavaScript가 자동으로 넣어 주므로(ASI) 동작은 정상이지만, do while 끝에는 붙이는 것이 관례} while (x < y);
출력 형식이 x = 20 45 = y로 읽기 어려움x = 20, y = 45
x++; y--; 한 줄, 들여쓰기 혼용, charset 없음정리
수정한 전체 코드 보기
<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="UTF-8">
<title>예제8-19 do while 반복문</title>
</head>
<body>
<h3>do while 반복문</h3>
<script>
    var x = 20, y = 45;
    do {                              // 먼저 1번 실행한 뒤 조건 검사
        document.write("do while : x = " + x + ", y = " + y + "<br>");
        x++;
        y--;
    } while (x < y);                  // x가 y보다 작은 동안 반복
</script>
</body>
</html>

한눈에 요약

문법언제 쓰나특징
if / else참·거짓 두 갈래조건이 참이면 if 블록, 아니면 else 블록
else if여러 구간 나누기위에서부터 검사, 처음 참인 것 하나만 실행
switch값이 딱 맞는지 비교break 필수, 없으면 아래 case까지 실행
for횟수가 정해진 반복초기식; 조건식; 증감식
이중 for표, 구구단 등 2차원바깥 1회당 안쪽 전체 반복
while횟수를 모르는 반복먼저 검사 → 0번 실행될 수도 있음
do while최소 1번은 실행해야 할 때먼저 실행 → 나중에 검사

※ 원본처럼 document.write()는 페이지를 처음 읽을 때만 써야 합니다. 페이지가 다 열린 뒤(버튼 클릭 등)에 쓰면 화면 전체가 지워지므로, 이 문서의 '실행해 보기'는 위 코드와 내용은 같게 하고 출력만 innerHTML로 바꿨습니다. (개발자 도구에서 <head>의 script를 열어 보면 확인할 수 있습니다.)
