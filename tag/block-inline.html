Block 요소 vs
Inline 요소

HTML 요소가 문서 흐름에서 어떻게 배치되는지 결정하는 display 속성의 핵심 개념을 시각적으로 이해합니다.

Block 요소
너비 부모의 100% 차지
줄바꿈 자동 앞뒤로 새 줄
width/height 적용됨
margin/padding 전 방향 적용
자식 포함 block + inline 모두 가능
대표 태그
divph1–h6 ul / ollisection articleheaderfooter tableformblockquote
Inline 요소
너비 콘텐츠 크기만큼만
줄바꿈 없음 같은 줄에 배치
width/height 무시됨
margin/padding 좌우만 정상 적용
자식 포함 inline 요소만 권장
대표 태그
spanastrong emimginput labelbuttoncode abbrbrsmall

Inline-Block — 두 세계의 조합

display: inline-block은 요소를 같은 줄에 배치하면서도 width, height, 상하 margin/padding을 모두 적용할 수 있습니다. 버튼, 태그, 뱃지처럼 "크기가 있는 인라인 요소"가 필요할 때 유용합니다.

코드 예시
<!-- Block 요소: 각자 새 줄 차지 --> <div style="background: #1a1f3c; padding: 8px;">첫 번째 블록</div> <div style="background: #1a1f3c; padding: 8px;">두 번째 블록</div> <!-- Inline 요소: 같은 줄에 나란히 --> <p> 텍스트 안에 <span>스팬</span>과 <strong>강조</strong>와 <a href="#">링크</a>가 함께 흐릅니다. </p> <!-- CSS로 display 바꾸기 --> <span style="display: block;">이제 block처럼 동작</span> <div style="display: inline;">이제 inline처럼 동작</div> <div style="display: inline-block; width: 120px;">인라인 + 크기 지정</div>
