Margin & Padding

요소 바깥 여백과 안쪽 여백의 차이를 Box Model 중심으로 이해합니다.

Box Model

모든 HTML 요소는 Content → Padding → Border → Margin 순서로 겹쳐진 박스 구조를 가집니다.

박스 모델 구조
MARGIN
PADDING

■ margin  |  ■ border  |  ■ padding  |  ■ content

Margin — 바깥 여백

요소와 다른 요소 사이의 거리입니다. 배경색이 적용되지 않으며 투명합니다.

margin으로 요소 간 간격 주기
Box A
margin-left: 8px
margin-left: 32px
margin: 0
margin: 0 auto (가운데 정렬)
margin: 10px 상하좌우 모두 10px
margin: 10px 20px 상하 10px / 좌우 20px
margin: 5px 10px 15px 상 5 / 좌우 10 / 하 15px
margin: 5px 10px 15px 20px 상 / 우 / 하 / 좌 (시계 방향)
.box { margin-top: 16px; margin-right: 8px; margin-bottom: 16px; margin-left: 8px; /* 단축: margin: 16px 8px; */ }
⚠️ Margin Collapse (마진 상쇄)
블록 요소의 상하 마진은 인접할 때 더 큰 값 하나로 합쳐집니다. 예) 위 요소 margin-bottom: 20px + 아래 요소 margin-top: 30px → 실제 간격은 30px.

Padding — 안쪽 여백

콘텐츠와 테두리(border) 사이의 공간입니다. 배경색이 그대로 채워집니다.

padding 크기에 따른 변화
padding: 0
텍스트
padding: 8px
텍스트
padding: 20px
텍스트
padding: 20px 40px
텍스트
.btn { padding: 10px 24px; /* 상하 10px, 좌우 24px */ background: #3a7bd5; /* padding 영역에도 background 적용됨 */ }

항목MarginPadding
위치 border 바깥 content 안쪽 (border 안)
배경색 영향 ❌ 투명 (적용 안 됨) ✅ 배경색이 채워짐
클릭 영역 ❌ 포함 안 됨 ✅ 포함됨
음수 값 ✅ 가능 (요소 당기기) ❌ 불가
auto 값 ✅ 가능 (가운데 정렬 등) ❌ 불가
상하 합산(collapse) ⚠️ 발생 (큰 쪽 하나만) ✅ 항상 그대로 합산
