CSS Fundamentals

Position

요소를 문서 흐름 안팎에서 어떻게 배치할지 결정하는 5가지 position 값을 예제로 이해합니다.

static

기본값. 문서의 일반 흐름(Normal Flow)에 따라 순서대로 배치됩니다. top / right / bottom / left / z-index가 모두 무시됩니다.

예제 — 순서대로 아래로 쌓임
Box 1 — position: static (default)
Box 2 — position: static
Box 3 — position: static
/* top, left 등 좌표값을 지정해도 아무 효과 없음 */ .box { position: static; /* 기본값 — 생략 가능 */ }

relative

원래 위치를 기준으로 이동합니다. 이동해도 원래 자리는 그대로 유지되어 주변 요소에 영향을 주지 않습니다. absolute 자식의 기준점으로도 자주 사용됩니다.

예제 — 원래 자리에서 top: 16px, left: 24px 이동
일반 요소
relative 이동 요소 ↑ top:16px left:24px — 원래 자리는 유지
.box { position: relative; top: 16px; /* 원래 위치에서 아래로 */ left: 24px; /* 원래 위치에서 오른쪽으로 */ }

absolute

문서 흐름에서 완전히 빠져나옵니다. 가장 가까운 position: static이 아닌 부모를 기준으로 배치됩니다. 해당 부모가 없으면 <html>이 기준이 됩니다.

예제 — position: relative 부모 안에서 절대 좌표 배치
부모 (position: relative)
top: 8px / right: 8px
bottom: 8px / left: 8px
.parent { position: relative; } /* 기준 부모 */ .child { position: absolute; top: 8px; right: 8px; }

fixed

뷰포트(브라우저 화면)를 기준으로 고정됩니다. 스크롤해도 항상 같은 자리에 머뭅니다. 내비게이션 바, 플로팅 버튼 등에 사용됩니다.

예제 — 오른쪽 상단에 실제 fixed 요소가 표시 중
📌 이 페이지 오른쪽 상단의 초록 배지가 position: fixed 로 동작 중입니다.
스크롤해도 항상 같은 위치에 고정되는 것을 확인하세요.
.navbar { position: fixed; top: 0; left: 0; width: 100%; z-index: 999; /* 다른 요소 위에 표시 */ }

sticky

relative + fixed의 조합. 평소에는 일반 흐름에 따라 배치되다가, 스크롤이 지정한 임계점에 닿으면 그 자리에 고정됩니다. 테이블 헤더, 섹션 제목 고정 등에 유용합니다.

예제 — 스크롤 영역 안에서 헤더가 상단에 고정됨
📌 Section A — sticky header (top: 0)

한눈에 요약
값 기준점 문서 흐름 스크롤 시 주 사용처
static 없음 유지 함께 스크롤 기본 배치
relative 원래 자신의 위치 유지 (자리 차지) 함께 스크롤 미세 조정, absolute 기준
absolute 가장 가까운 non-static 부모 이탈 (자리 없음) 부모와 함께 이동 툴팁, 드롭다운, 뱃지
fixed 뷰포트 이탈 (자리 없음) 화면에 고정 상단 바, 플로팅 버튼
sticky 스크롤 컨테이너 유지 (자리 차지) 임계점에서 고정 테이블 헤더, 섹션 제목
