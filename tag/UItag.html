HTML 구조 태그와 반응형 웹

1. HTML UI 구조 태그

<header>

웹페이지의 상단 영역을 구성하는 태그입니다.

  • 사이트 로고
  • 홈페이지 제목
  • 상단 메뉴

<nav>

메뉴와 링크를 배치하는 태그입니다.

  • 메인 메뉴
  • 카테고리 메뉴
  • 페이지 이동 링크

<main>

웹페이지의 핵심 내용을 담는 태그입니다.

※ HTML에서는 <content>보다 <main> 사용이 적절합니다.

<footer>

웹페이지 하단 정보를 표시하는 태그입니다.

  • 저작권 정보
  • 작성자 정보
  • 참고 자료

2. 홈페이지 기본 구조

<body>
    <header>상단 영역</header>
    <nav>메뉴 영역</nav>
    <main>본문 영역</main>
    <footer>하단 영역</footer>
</body>

3. 반응형 웹

반응형 웹은 PC, 태블릿, 스마트폰처럼 화면 크기가 다른 장치에 맞게 홈페이지 배치를 자동으로 바꾸는 웹 디자인 방식입니다.

4. 디스플레이 장치에 따른 배치

PC 화면

Header
Nav | Content
Footer

스마트폰 화면

Header
Nav
Content
Footer

5. 미디어 쿼리

미디어 쿼리(Media Query)는 화면 크기에 따라 다른 CSS(Cascading Style Sheets)를 적용하는 기능입니다. 

@media (max-width: 768px) {
    .layout {
        flex-direction: column;
    }
}

6. 요약

태그 역할
<header> 상단 영역
<nav> 메뉴 영역
<main> 본문 영역
